# OldPipe-2012
OldPipe - is a 2012 Cosmic Panda (YouTube 2012) Frontend project that is built using the InnerTube API, and also uses ffmpeg, ytdlp, YouTube Data API V3, Google OAuth api and a lot of other stuff
![OldPipe logo](assets/logo/OldPipe.png)
# How to install?
Download XAMPP and Fiddler Classic. To install it, you need to put it in the htdocs folder, and then in Fiddler Classic, u need to go on the tools, options, and u should turn the 3 options, and also you should set up the protocol shown in the screenshot.
